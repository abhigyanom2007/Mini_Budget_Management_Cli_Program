## Problem Statement
It's easy for college students to lose track of where their money goes. Most budgeting apps are either too complicated, filled with ads, or push you to link your bank accounts. I wanted to build a fast, simple terminal-based tool where someone can log their expenses quickly without dealing with spreadsheets or clunky interfaces.

## Scope of the Project
This is a purely command-line financial tracker. The scope is kept to the essentials: taking user input for income and expenses, saving the data locally in a JSON file, and calculating the net balance. It handles basic user typos but skips overly complex features like encryption or API integrations.

## Target Users
* College students trying to manage their monthly allowances or part-time income.
* People who like using lightweight terminal tools instead of heavy web apps.
* Anyone looking for a simple, private way to track their cash flow.

## High-Level Features
* Interactive text-based menu.
* Create and view transaction records.
* Live net balance calculation.
* Local data storage using JSON.
