# Mini Budget CLI

## Overview
Mini Budget is a simple command-line app I built to track personal finances. It lets you quickly log your income and expenses, check your transaction history, and see your current net balance. I created this as my final project for the Python Essentials course.

## Features
* **Manage Transactions:** Easily add new income or expenses along with a short description.
* **Track Balance:** The app automatically calculates your total income, total expenses, and current net balance.
* **Auto-Save:** Everything saves instantly to a local `budget_data.json` file, so you don't lose your data when you close the script.
* **Crash Prevention (Error Handling):** If you accidentally type a letter instead of a number for a price, the app will warn you instead of breaking.

## Tech Stack
* **Language:** Python 3.x
* **Libraries:** `json`, `os` (I only used built-in Python libraries, so there are no pip installs required)
* **Version Control:** Git & GitHub
